QKD-Lab is an educational BB84 simulation. The 11% rule is an illustrative classroom threshold, not a security certificate: a high error rate can come from an eavesdropper or from noise, and a clean run bounds risk rather than proving it absent. This tool does not provide production key distribution, error correction, privacy amplification or a security proof.
